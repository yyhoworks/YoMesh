# MosDNS 能力与 LocalDNS 边界

MosDNS 工作台按常见独立 DNS 的配置需求组织，而不是把 LocalDNS JSON 改名导出。所有生成内容从 `Profile.mosdns` 统一解析，目标版本为 MosDNS 5.3.4。

## 已提供的配置

| 需求 | 实现 |
|---|---|
| 监听与管理 | 独立地址、端口、UDP / TCP、可选 API、日志级别 |
| 多类上游 | 国内、国外、国外 ECS、Mihomo DNS 四组；逐上游启停、固定拨号 IP、SOCKS；同组并发 |
| ECS | 各组独立 IPv4 / IPv6 网段；转换为原生 IP preset 与 mask |
| 缓存 | 主缓存和各组缓存，容量、过期保留、落盘与间隔；新建默认 1024 条 |
| 查询处理 | AAAA 空应答、明确的 QTYPE 拦截列表、TTL 上下限 |
| 规则 | 有序域名、客户端 IP / CIDR、查询类型；上游动作或拒绝 |
| 重写 | 域名表达式对应固定 IPv4 / IPv6 |
| 主备回退 | 主 / 备用上游、阈值、并行准备，可根据响应 CIDR 判定 |
| 来源更新 | 域名与响应 IP 来源，文本、受支持 YAML、SRS / MRS；工作台定时刷新，失败保留快照 |
| 高级编辑 | 完整原生 JSON，未知字段交给实际内核验证 |

同一条件的多值按 OR，域名、客户端与 QTYPE 三类条件之间按 AND。按顺序首次匹配即停止；停用跳过整条规则。客户端分流需要关闭主缓存、改用组缓存。

IP 规则在响应 IP 阶段使用，不把 IP 条件删掉后变成纯域名条件。源文件含混合条件或无法等价转换的语法时整条拒绝，不做部分过滤。仅支持基础 AdGuard 域名规则，例外、元素过滤和修饰符不能直接转换。

来源更新发生在工作台；部署中的 MosDNS 读取导出时快照，需要重新导出和部署。保存设置、预览或导出不会启动目标设备的 DNS 服务。

## 不自动迁移的能力

- LocalDNS 动态 FakeIP / realip / nodata 表及统计容量。
- 路由缓存、审计存储、客户端名称和程序特有客户端策略。
- 定时重新查询、外部 URL 动作和完整 AdGuard 扩展语法。
- 宿主机内存上限、网络接管和服务管理。

这些能力不是 MosDNS 同名字段，需额外的运行时服务或明确的等价适配。可把已运行的 Mihomo DNS 作为上游，但不意味着工作台实现了动态 FakeIP 服务。

已有 `mihomo-localdns-v1` 以原件为准，默认工作台与导出使用 LocalDNS。另存 MosDNS 不修改原代理文档与 LocalDNS 文件，也不替代默认内核或声称完成完整迁移。兼容字段依据见 [兼容约定](compatibility.md)。

高级配置现在可从已保存的 LocalDNS 原件生成表单草稿，同时列出已读取、待核对和未等价迁移项。规则与 IP 来源先保存为停用状态；确认动作和优先级后可自行启用。报告未确认时允许保存草稿，阻止校验及导出，避免将待核对配置当成已完成迁移。
