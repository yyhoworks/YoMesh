# 公开版本与私有数据

公开仓库只包含代码、通用说明、版本锁、许可证资源与明确标注的合成测试样例。

以下内容不进入版本库：

- `data/` 中的真实 Profile、订阅、节点账号、证书、会话和数据库。
- 本机设备快照、迁移原件、部署备份、诊断输出与截图。
- `.env`、个人 Compose 覆盖、SSH 配置与私钥。
- 下载的内核程序、第三方私有程序、依赖缓存与构建产物。

部署地址通过本地环境变量配置。文档中的 `example.com`、文档保留地址及测试密码均为示例；通用 RFC1918 私网网段是匹配规则语义，不是用户设备清单。

公开问题与截图前，请自行检查请求地址、订阅令牌、节点凭据、证书、路径和客户端信息。程序原生校验失败时不会把内核原始输出中的节点密码反射到工作台日志。

默认不把历史运行目录加入 Git。新增文件前使用 `git diff --cached` 检查实际暂存内容；仅依赖 `.gitignore` 不能清除已提交的秘密。
